BEFORE YOU START

先准备好知识库

庖丁在你的电脑上运行。接入前，确保电脑和 PostgreSQL 服务正在运行；要处理新内容，还需要 Worker。

  1. 打开知识库，确认页面能正常加载。
  2. 在模型设置中配置至少一个可用模型，然后通过收录页提交内容。
  3. 等待任务处理成功；如果知识库还是空的，检索工具会正常返回空结果。
本页的示例不会包含你的 API Key 或授权令牌。正式内容通过你的模型服务处理，可能产生相应费用。
01 / FOR AGENTS

连接 AI Agent

适合支持 MCP 的桌面 Agent。此方式由客户端在同一台电脑上启动本地进程，不需要填写一个远程 MCP 网址。

  1. 确认庖丁项目依赖已安装，数据库正在运行。
  2. 在 Agent 的 MCP 配置中新增下方配置。将 /你的项目路径/Paoding 替换为你电脑上项目的绝对路径；如果客户端找不到 uv，将 command 改成 uv 的绝对路径。
  3. 保存配置，重新加载或重启 Agent；在工具列表中查找 paoding-mcp。
  4. 先收录内容，再让 Agent 按类型或标签检索。
MCP 配置示例 · 路径需替换
{
  "mcpServers": {
    "paoding": {
      "command": "uv",
      "args": ["--directory", "/你的项目路径/Paoding", "run", "paoding-mcp"]
    }
  }
}

连接后可以说：“从庖丁里找适合小红书的视觉元件，并说明可迁移的方法。”

02 / FOR PRODUCTS

连接网页产品

你的网页产品可以从自己的后端调用庖丁 API，展示卡片、搜索知识，或者提交新的收录任务。

  1. 同机接入时，将基础地址设置为 http://127.0.0.1:8010/api/v1。
  2. 先调用知识库列表接口，确认返回数据；若列表为空，先完成一次内容收录。
  3. 通过卡片 ID 调用详情接口。提交链接后，使用返回的 job_id 查询状态，成功后再读取结果。
  4. 如果设置了 PAODING_API_TOKEN，在请求头中添加 Authorization: Bearer 你的令牌。
搜索知识卡片 · 本机终端
curl -G 'http://127.0.0.1:8010/api/v1/library' \
  --data-urlencode 'q=营销'

03 / ACROSS DEVICES

手机和跨设备访问

知识库已有适合手机屏幕的网页布局，可以浏览卡片、搜索、筛选、查看详情和提交链接；当前收录页主要接收链接。

  1. 保持运行庖丁的电脑和数据库在线。
  2. 先建立受保护的跨设备连接，例如在电脑和手机上配置同一个 Tailscale 网络及 HTTPS 入口。
  3. 在对外提供 API 访问前，配置长随机 PAODING_API_TOKEN，并通过可信的安全通道传输；按部署方式检查访问范围。
  4. 用手机浏览器打开配置好的专用地址，在页面提示时填写庖丁访问令牌。
当前状态：服务默认只监听电脑本机，手机直接打开 127.0.0.1:8010 无法访问电脑。跨设备网络与 HTTPS 入口不会自动创建；模型和密钥设置页面仅允许本机访问。
HELP / 常见问题

遇到问题？

Agent 连接了，但查不到内容？

先打开知识库，确认已经有处理成功的卡片。MCP 返回空列表可以表示知识库为空或筛选条件没有匹配，并不一定是连接失败。

模型已授权，为什么收录还失败？

同步模型列表不等于完成实际生成测试。请在模型设置中测试单个模型，并在最近任务中检查处理状态。特定平台还可能需要采集服务或登录权限。

我需要把密钥发给 Agent 吗？

不要把模型密钥或 OAuth 令牌放在聊天、公开网页或代码仓库中。本机 MCP 由客户端启动并读取本机配置；HTTP 接入如启用了访问令牌，应仅交给可信后端并使用安全连接。

为什么任务“已接单”后还没有卡片？

已接单表示任务进入队列。请确认 Worker 正在运行，并在知识库的最近任务查看处理结果；处理成功后卡片才会出现。
