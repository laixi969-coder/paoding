# PRD v1.0 对照与待验收事项

本页区分已编写的能力和依赖外部环境才能完成的真实验收；自动化测试通过不等同于所有第三方服务可用。

| PRD 模块 | 已具备 | 尚需条件或限制 |
| --- | --- | --- |
| 投喂、任务、账号巡检 | URL、文件夹、CLI、书签收录，持久队列、账号巡检、任务重试；工作台可看任务和账号画像 | 各平台实际可抓取范围受登录和上游接口限制；历史 Top 20 取决于采集端能返回完整、可排序的数据 |
| 跨平台采集 | TikHub、yt-dlp、gallery-dl、RSS、WorkBuddy 导出、网页及文档适配 | TikHub、WeWe-RSS、RSSHub、MinerU、WorkBuddy 和平台登录需自行配置；视频号依赖导出文件或自有采集网关，未内置视频号抓包解密；MediaCrawler 需自行部署并通过 Collector Bridge 适配 |
| 移动 Bot | Telegram、飞书、企业微信 Webhook、附件、异步处理与通知 | 需要各自账号、权限、外网 HTTPS 回调及真实消息联调 |
| 多模型与三刀 | 多厂商与自定义服务商、模型列表、单模型测试、路由和回退、视频/图片/文字分析 | 模型是否支持对应模态需用自己的账户验证；故障回退受网络连接与响应超时影响，不能保证所有故障均在 1 秒内切换 |
| 知识库与存储 | PostgreSQL + 本地 Markdown 双写、工作台浏览/关键词搜索/筛选/详情、原子元件反馈与归档状态 | 关键词搜索非语义搜索；向量检索需要配置向量模型和 PostgreSQL/pgvector；Markdown 手工改动不会反向同步数据库 |
| 自进化与 MCP | 趋势、创作者画像、元规则、分类树、反馈衰减、调度和五个 MCP 工具；工作台可查看结果并触发整理 | 需要足够的真实卡片、账号样本及可用模型才能产生有意义的结果；模型输出质量和来源需人工核实 |
| 部署与多设备 | macOS 本地启动、Docker PostgreSQL、PM2 配置、Windows 启动脚本 | Windows、实际 Bot/平台及多机 Tailscale/Syncthing 仍需在目标设备和账户上联调；本项目不会替用户自动登录或配置这些外部服务 |

各服务准备步骤见 [配置总清单](configuration.md)，协议范围见 [接入状态](integrations.md)。
